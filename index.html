Progress

  • Ported the CPU path tracer to CUDA: ray generation (one thread per pixel), BVH, ray–triangle intersection, direct lighting and BSDFs.
  • The whole scene is flattened into pointer-free arrays and uploaded to the GPU in one GPUScene.

How

  • No polymorphism: one struct per object kind with a type enum and switch statements instead of virtual calls. Most objects have a toGPU() method.
  • Flat BVH: nodes, boxes and primitive order live in arrays; children are indices. Traversal is an iterative loop with a small per-thread stack instead of recursion.
  • Rendering: once the data was on the GPU, the CPU lighting code carried over almost unchanged.
