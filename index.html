Current progress

  • Most features of the CPU path tracer ported to CUDA: camera ray generation (one thread per pixel), BVH construction and ray–triangle intersection, direct lighting and BSDFs.
  • The whole scene is flattened and uploaded to the GPU alongside the framebuffer. Primitives are plain structs with no pointers; BSDFs are copied once and referenced by id.

Flattening: polymorphism is bad for GPUs

The starter code relies on virtual dispatch (e.g. intersect for spheres vs. triangles). We want everything in a scene stored in arrays we can simply index.

  • Shared features collapse into one reusable struct; a switch on a type enum handles child-specific behavior (BSDF f, light sample_L).
  • Primitives store triangle points and normals in vectors; spheres reuse them for origin, radius and radius² (x and y of b).
  • Most objects gain a toGPU() that builds a GPU-equivalent struct. GPU versions of the sampling and intersection functions were mostly copy-paste.

GPU scenes

Primitives, BVH nodes, BSDFs and lights live in one GPUScene struct (the single camera is passed at render time). An upload function mallocs space for each and copies them over, with a matching free. After that, zero- and one-bounce (importance-sampled) lighting was the CPU code with GPU structs swapped in.

BVH without pointers or recursion

  • Built from arrays of bounding boxes, nodes and a primitive order; same midpoint-of-longest-centroid-axis split as our CPU version.
  • Left/right children are indices into the node array, root at 0; leaves store a range of primitives.
  • Traversal is an iterative loop over a fixed-size per-thread stack of node indices.
__device__ inline bool intersect_scene(
    const GPUSceneView &scene, GPURay r, GPUIntersect &hit) {
  hit.prim_id = -1; hit.t = r.max_t;
  if (scene.num_nodes == 0) return false;
  int stack[GPU_BVH_STACK_SIZE], sp = 0;
  stack[sp++] = 0; // root
  while (sp > 0) {
    const GPUBVHNode &node = scene.nodes[stack[--sp]];
    if (!intersect_bbox(node.bb_min, node.bb_max,
                        r, r.min_t, r.max_t)) continue;
    if (node.count > 0) { // leaf
      int end = node.start + node.count;
      for (int i = node.start; i < end; i++)
        intersect_primitive(scene, i, r, hit);
    } else {
      stack[sp++] = node.right;
      stack[sp++] = node.left;
    }
  }
  return hit.prim_id >= 0;
}
